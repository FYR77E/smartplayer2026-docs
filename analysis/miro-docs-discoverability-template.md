# Miro Template — Docs Discoverability V1

## Frame 1 — Scope
- Operational docs pages
- In-page next-step guidance
- Cross-links between related sections

## Frame 2 — Issues
- Pages explained one topic well, but often ended without a next move
- Users could lose momentum between devices, content, broadcasts, schedules, and troubleshooting
- Deep docs discoverability lagged behind the improved home/onboarding layer

## Frame 3 — Decisions
- Keep the current docs structure
- Do not redesign the content model
- Improve only local discoverability and reading flow

## Frame 4 — Fixes
- Added `Куда идти дальше` callouts
- Added `Связанные материалы` lists
- Connected operational sections more explicitly

## Frame 5 — Outcome
- Stronger reading flow inside docs
- Less need to bounce back to the homepage
- Better continuity between core operational pages

## Frame 6 — Verification
- `check:release:full`
- Live checks for the updated docs pages
