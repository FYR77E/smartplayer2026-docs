# Miro Template — Quick Start Reading Flow V1

## Frame 1 — Scope
- Route: `/quickstart/`
- Pass type: medium/mobile reading flow
- Goal: make the route easier to scan and easier to continue after completion

## Frame 2 — Issues
- Five route-switching pills wrapped into a noisy cluster on medium/mobile
- Top explanatory note was a dense inline paragraph
- Completion state did not strongly surface the next operational step

## Frame 3 — Decisions
- Keep Quick Start as a standalone screenshot-based guide
- Do not rewrite source-of-truth product content
- Improve structure, not concept

## Frame 4 — Fixes
- Responsive route switcher layout
- Structured top note instead of dense inline paragraph
- New `Что дальше после Quick Start` section
- Checklist label aligned with the rest of the platform

## Frame 5 — Outcome
- Faster scan at the top of the page
- Cleaner transition from Quick Start to checklist
- Better separation between:
  - quick start
  - interactive tour
  - full docs
