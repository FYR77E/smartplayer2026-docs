# Docs B-lite Pilot Pass V1

## Что сделали
- Добавили лёгкий atom layer для docs: `Note`, `UiPath`, `Kbd`, `Screenshot`.
- Собрали первую curated docs-страницу: `Быстрая отправка — практический сценарий`.
- Встроили пилот в sidebar и в связанный docs-слой через cross-links из разделов про трансляции и расписания.

## Почему так
- Не стали тянуть тяжёлую миграцию всего контента в новый компонентный слой.
- Не трогали `quickstart-site` и `interactive-tour` как отдельные поверхности.
- Взяли только то, что реально помогает: чище читать, легче поддерживать, проще развивать пилотные сценарии.

## Что проверяем
- Пилотная страница ощущается как часть текущей платформы, а не чужой микросайт.
- Новый atom layer не конфликтует с существующим `ManualContent`.
- Release-gates остаются зелёными.
