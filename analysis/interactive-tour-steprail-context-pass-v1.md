# Interactive Tour — Step Rail & Context Pass V1

## Что улучшили
- Текущий step chip теперь автоматически докручивается в видимую область rail на узких экранах.
- Внутри frame bar появился короткий контекст текущего шага: номер шага и короткое название.
- DESIGN.md обновлён: зафиксированы два правила для active-state — текущий chip всегда остаётся видимым, а контекст шага должен читаться даже ниже progress header.

## Почему это было нужно
- На mobile и medium пользователь мог уйти дальше по туру, но активный chip оказывался частично вне видимой области rail.
- Когда progress header уходил выше fold, внутри самого screenshot-frame не хватало компактного напоминания, какой шаг сейчас открыт.

## Что проверили
- Автоскролл rail не конфликтует с основным viewport scroll тура.
- На mobile QA теперь дополнительно проверяет, что активный chip остаётся в пределах видимой области rail.
