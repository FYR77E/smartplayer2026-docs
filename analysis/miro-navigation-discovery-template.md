# SmartPlayer Docs — Miro Template For Navigation And Discovery

## Source Scope

- Focus: `navbar`, `footer`, `docs discovery`

## How To Add This Into Miro

1. Создай новый frame group `Navigation And Discovery`.
2. Сделай 4 frame'а по структуре ниже.
3. Каждый bullet — отдельный sticky.
4. Цвета:
   - yellow — facts
   - pink — frictions
   - green — decisions
   - blue — next actions

## Frame 1 — Entry Points

- Documentation
- Пошаговый старт
- Интерактивный тур
- Чек-лист перед запуском
- Full manual

## Frame 2 — Frictions Fixed

- Footer говорил `Интерактивное обучение`
- Navbar и home описывали старт по-разному
- Checklist назывался менее явно как финальный gate
- Docs discovery не перечислял стартовые entry points достаточно явно

## Frame 3 — Decisions

- Использовать одну и ту же терминологию в navbar и footer
- `Интерактивный тур` = каноническое название walkthrough
- `Пошаговый старт` = каноническое краткое название Quick Start entry point
- `Чек-лист перед запуском` = финальный gate label

## Frame 4 — Next Actions

- Проверить mobile reading flow Quick Start
- Проверить footer discovery после следующих изменений
- Сохранять terminology consistency в новых docs pages
