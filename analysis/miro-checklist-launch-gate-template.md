## How To Add This Into Miro

1. Создай новый frame group `Checklist As Launch Gate`.
2. Сделай 4 frame'а по названиям ниже.
3. Каждый bullet ниже — это отдельный sticky.
4. Цвета:
   - yellow — facts
   - pink — frictions
   - green — decisions
   - blue — next actions

## Frame 1 — Current Journey

- Interactive Tour
- Quick Start со скриншотами
- Checklist
- Pilot verification
- Mass rollout
- Launch regulation

## Frame 2 — Problems We Fixed

- Checklist выглядел как обычный соседний раздел
- После Quick Start не было достаточно явного next step
- В Tour checklist не читался как контроль перед пилотом
- Redirect page checklist был слишком нейтральным

## Frame 3 — Decisions

- Checklist = финальная сверка перед пилотом и rollout
- Quick Start = execution path
- Tour = visual orientation
- После Quick Start пользователь должен видеть путь в checklist
- Checklist должен быть связан с launch regulation

## Frame 4 — Next Actions

- Проверить, достаточно ли checklist заметен на home
- При следующем pass оценить footer/nav terminology вокруг launch flow
- При будущих изменениях Quick Start сохранять путь `Quick Start -> Checklist`
- Если launch flow станет сложнее, вынести отдельную visual map в board
