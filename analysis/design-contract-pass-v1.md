# Design Contract Pass V1

## Focus
- Create a project-level design contract so future polish passes stay consistent.

## Output
- Added `DESIGN.md` at the repo root.

## What it covers
- product surfaces and their roles
- CTA hierarchy
- visual language
- typography and tone of voice
- interactive-tour rules
- quickstart rules
- completion-state rules
- mobile rules
- anti-patterns to avoid
- definition of done for polish passes

## Why it matters
- Reduces generic design drift.
- Makes future agent work more consistent.
- Turns the recent UI/UX improvements into reusable project guidance instead of one-off fixes.
