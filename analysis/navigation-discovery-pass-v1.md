# SmartPlayer Docs — Navigation And Discovery Pass V1

## Goal

Сделать стартовый маршрут одинаково читаемым в `navbar`, `footer` и базовом docs-discovery слое.

## Issues Found

1. В `footer` оставалась старая формулировка `Интерактивное обучение`, хотя в остальном продукте уже используется `Интерактивный тур`.
2. В `navbar` и `footer` Quick Start и Checklist назывались по-разному по смыслу, чем на главной.
3. В generated-index для стартовой категории не хватало явного перечисления стартовых entry points.

## Changes Made

### Navbar

- `Быстрый старт` -> `Пошаговый старт`
- `Чек-лист запуска` -> `Чек-лист перед запуском`

### Footer

- `Быстрый старт` -> `Пошаговый старт`
- `Интерактивное обучение` -> `Интерактивный тур`
- `Чек-лист запуска` -> `Чек-лист перед запуском`

### Docs discovery

- Обновлено описание generated-index для категории `Старт и ориентация`
- Теперь там явно перечислены:
  - обзор
  - пошаговый старт
  - интерактивный тур
  - чек-лист перед запуском

### Interactive Tour page metadata

- Title приведён к той же формулировке: `Интерактивный тур`

## Expected Effect

1. Пользователь видит одну и ту же продуктовую терминологию в главной навигации и в footer.
2. Стартовый маршрут читается как связанная система:
   - docs overview
   - пошаговый старт
   - интерактивный тур
   - чек-лист перед запуском
3. Снижается ощущение, что разные entry points ведут в разные по смыслу продукты.
