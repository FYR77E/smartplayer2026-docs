## 6.1. Раздел "Трансляции"

<ManualLead text="Раздел `Трансляции` объединяет созданные сценарии показа, которые можно редактировать, группировать и использовать в расписаниях." />

Раздел состоит из трех основных пунктов:

- `Создать` - открывает редактор трансляции.
- `Видеостена` - открывает редактор с заранее подготовленными зонами под сценарий видеостены.
- `Добавить папку` - помогает структурировать созданные трансляции по папкам.

## 6.2. Создание интерактивных трансляций

Для создания трансляции необходимо выбрать раздел «Трансляции» под пункт «Создать». Откроется окно редактора трансляции.

После запуска редактора доступны:

<ManualFigure src="/img/manual/image35.webp" alt="6. Работа с трансляциями" />

- рабочее поле (по умолчанию Full HD, горизонтально);
- имя трансляции;
- блок настроек;
- Timeline/плейлист;
- панель выбора контента.

## 6.3. Настройка рабочего поля

Если требуются нестандартные параметры:

1. Откройте настройки страницы.
1. Задайте ширину и высоту в пикселях.
1. Сохраните изменения.

## 6.4. Добавление зон

Зону можно создать:

- через готовые шаблоны;
- вручную на рабочем поле.

Рекомендация: зоны должны покрывать требуемую область экрана без пустых участков, если по сценарию не предусмотрены поля. Пример настройки зоны:

## 6.5. Добавление контента в трансляцию

Контент добавляется перетаскиванием в выбранную зону. Для многозонного сценария каждая зона заполняется отдельно.

## 6.6. Управление очередностью и длительностью контента

В Timeline доступны:

<ManualFigure src="/img/manual/image31.webp" alt="6. Работа с трансляциями" />

- изменение порядка воспроизведения;
- изменение позиции по времени;
- удаление единицы контента;
- настройка длительности;
- настройка громкости;
- зацикливание;
- выравнивание и масштабирование.

Изменяемая длительность поддерживается для статичного контента:

- изображений;
- документов;
- веб-источников;
- бегущей строки;
- табличных документов;
- виджетов.

## 6.7. Правильное построение контента

Чтобы избежать разрывов на Timeline:

- включите автоматическое непрерывное расположение контента;
- при необходимости пересчитайте длительность страницы по фактическому контенту;
- для нескольких зон используйте зацикливание в более коротких зонах.

## 6.8. Изменение порядка воспроизведения

Для случайного порядка включите режим перемешивания в настройках зоны.

## 6.9. Многостраничные трансляции

Редактор поддерживает несколько страниц (листов) в одной трансляции. Настройки и контент каждой страницы формируются независимо.

## 6.10. Дополнительные настройки трансляции

Дополнительные инструменты редактора:

- отмена/повтор действий;
- масштабирование рабочего поля;
- варианты растягивания контента;
- настройка анимаций;
- добавление таблиц;
- клонирование и вставка элементов.

## 6.11. Завершение работы и сохранение

Перед сохранением:

1. Проверьте название трансляции.
1. Проверьте настройки всех зон и страниц.
1. Сохраните трансляцию.
1. При необходимости выйдите без сохранения изменений.

## 6.12. Использование созданной трансляции

Из карточки трансляции доступны:

- клонирование;
- переход к назначению расписания;
- редактирование;
- удаление (если трансляция не задействована в расписаниях).
