## 9.1. Дистрибутивы

<ManualLead text="Раздел содержит актуальные дистрибутивы клиентского ПО для поддерживаемых платформ. Для локального сервера возможна отдельная сборка с учетом сетевой конфигурации заказчика." />

Используйте этот раздел, когда нужно:

- получить актуальный клиентский пакет для поддерживаемой платформы;
- сверить доступные варианты поставки для локального контура;
- подготовить материалы для установки или обновления клиентского ПО.
