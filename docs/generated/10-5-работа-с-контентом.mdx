## 5.1. Раздел "Контент"

![5. Работа с контентом](/img/docx/c49295a0e8e8d816.png)

Раздел отображает весь загруженный контент. В зависимости от сценария внедрения данные хранятся:

в облаке SmartPlayer (CMS);

на локальном сервере заказчика.

## 5.2. Способы загрузки контента

Drag and Drop из файловой системы;

загрузка локального файла;

загрузка с Яндекс Диска;

загрузка по URL из сети.

## 5.3. Создание папок и структура хранения

Рекомендуется заранее структурировать контент по папкам и типам. 
Базовые категории:

![5. Работа с контентом](/img/docx/7283f2ca07afbd34.png)

всё;

изображения;

видео;

музыка;

документы;

web источники;

медиа поток;

текст;

таблицы;

виджеты;

## 5.4. Видеоредактор

![5. Работа с контентом](/img/docx/5bf65b737ebbe39b.png)

Система SmartPlayer предоставляет возможность пользователям внести изменения в загруженный в систему контент для корректного отображения информации.

![5. Работа с контентом](/img/docx/ec47ade501b87ce2.png)

Выбирая нужную единицу контента, пользователь может внести следующие изменения:

длительность;

разрешение;

битрейт;

частота кадров;

поворот;

удаление аудиодорожки.

После обработки создается новая версия файла, доступная для сохранения в библиотеке контента.

## 5.5. Раздел "Контент на устройства"

Данный функционал позволяет пользователю быстро и пошагово подготовить трансляцию для отправки контента на устройство(а).

![5. Работа с контентом](/img/docx/2937c641ef463a9a.png)

Раздел позволяет быстро создать и отправить публикацию на устройства:

подготовить трансляцию;

назначить ее на устройства;

настроить расписание;

выполнить быстрые замены в эфире.

5.6. Создание пошаговой трансляции

Устанавливается нужное разрешение и ориентация, нажав на → ⚙️ (по умолчанию, новая трансляция в данном методе, с разрешением 1920x1080)

Задается наименования новой трансляции

Добавляется контент из правой области в рабочую зону – возможно добавление файлов, как и путем Drag & Drop или выбрать нужные файлы или папку и нажать “Добавить”

В Timeline будет показан весь добавленный контент и его порядок воспроизведения, также можно менять порядок воспроизведения файлов, удалять, и заменять.

![5. Работа с контентом](/img/docx/9473f930062a7b30.png)

Для предпосмотра всей трансляции в Timeline нажмите на иконку Play.

При выборе статичного файла можно перейти в раздел “Настройки контента” и при необходимости поменяйте длительность контента.

![5. Работа с контентом](/img/docx/18214b414b0ab353.png)

После нажатия на иконку “Сохранить” – осуществляется переход в следующий раздел.

5.7. Выбор устройств

В данном разделе пользователь определяет целевые устройства для назначения трансляции.

![5. Работа с контентом](/img/docx/0bbf7892dae55b19.png)

Выбирается, на какие устройства или группы назначить трансляцию.

После выбора устройств необходимо нажать “Далее”

5.8. Настройка расписания

![5. Работа с контентом](/img/docx/22baa4b4f8e0f58f.png)

В разделе Расписание пользователь настраивает время, частоту показа (навсегда, ежедневно или в конкретный день). Также задет временной интервал выхода.

6. Работа с трансляциями

## 6.1. Раздел "Трансляции"

Данный раздел представляет собой меню со всеми созданными трансляциями, которые могут быть как участниками расписания, так и заготовками для последующих расписаний.

Раздел состоит из 3х пунктов:

Создать – открывается редактор трансляции

Видеостена – позволяет открыть редактор трансляции с заранее предсозданными зонами согласно заданным параеметрам видеостены

Добавить папку – функционал, предназначенный для струткурирования созданных трансляций по аналогии с группировками устройств

## 6.2. Создание интерактивных трансляций

Для создания трансляции необходимо выбрать раздел «Трансляции» под пункт «Создать». Откроется окно редактора трансляции.

![5. Работа с контентом](/img/docx/c1129e9a5a29419e.png)

После запуска редактора доступны:

рабочее поле (по умолчанию Full HD, горизонтально);

имя трансляции;

блок настроек;

Timeline/плейлист;

панель выбора контента.

## 6.3. Настройка рабочего поля

Если требуются нестандартные параметры:

1. Откройте настройки страницы.

2. Задайте ширину и высоту в пикселях.

3. Сохраните изменения.

## 6.4. Добавление зон

Зону можно создать:

через готовые шаблоны;

вручную на рабочем поле.

![5. Работа с контентом](/img/docx/d101868a73cea7a3.png)

Рекомендация: зоны должны покрывать требуемую область экрана без пустых участков, если по сценарию не предусмотрены поля. Пример настройки зоны:

![5. Работа с контентом](/img/docx/4ec687b395f07954.png)

Рисунок 11 - Добавление и настройка зон в редакторе (источник: стр. 22)

## 6.5. Добавление контента в трансляцию

Контент добавляется перетаскиванием в выбранную зону. 
Для многозонного сценария каждая зона заполняется отдельно.

## 6.6. Управление очередностью и длительностью контента

В Timeline доступны:

![5. Работа с контентом](/img/docx/9473f930062a7b30.png)

изменение порядка воспроизведения;

изменение позиции по времени;

удаление единицы контента;

настройка длительности;

настройка громкости;

зацикливание;

выравнивание и масштабирование.

![5. Работа с контентом](/img/docx/d101868a73cea7a3.png)

Изменяемая длительность поддерживается для статичного контента:

изображений;

документов;

веб-источников;

бегущей строки;

табличных документов;

виджетов.

## 6.7. Правильное построение контента

Чтобы избежать разрывов на Timeline:

включите автоматическое непрерывное расположение контента;

при необходимости пересчитайте длительность страницы по фактическому контенту;

для нескольких зон используйте зацикливание в более коротких зонах.

## 6.8. Изменение порядка воспроизведения

Для случайного порядка включите режим перемешивания в настройках зоны.

## 6.9. Многостраничные трансляции

Редактор поддерживает несколько страниц (листов) в одной трансляции. Настройки и контент каждой страницы формируются независимо.

## 6.10. Дополнительные настройки трансляции

Дополнительные инструменты редактора:

отмена/повтор действий;

масштабирование рабочего поля;

варианты растягивания контента;

настройка анимаций;

добавление таблиц;

клонирование и вставка элементов.

## 6.11. Завершение работы и сохранение

Перед сохранением:

1. Проверьте название трансляции.

2. Проверьте настройки всех зон и страниц.

3. Сохраните трансляцию.

4. При необходимости выйдите без сохранения изменений.

## 6.12. Использование созданной трансляции

Из карточки трансляции доступны:

клонирование;

переход к назначению расписания;

редактирование;

удаление (если трансляция не задействована в расписаниях).
