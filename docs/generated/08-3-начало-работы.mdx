После получения данных от представителя SmartPlayer для авторизации в личном кабинете, клиент может осуществить вход в личный кабинет посредством Web-браузера.

## 3.1. Авторизация в личном кабинете

![Рисунок 1 - Окно входа в личный кабинет](/img/manual/image11.png)

*Рисунок 1 - Окно входа в личный кабинет*

Доступ к системе выполняется через веб-интерфейс CMS SmartPlayer. Пользователь вводит логин (электронную почту) и пароль в форме входа.

При успешной авторизации открывается рабочая область личного кабинета. При ошибке система выводит сообщение о некорректных учетных данных.

## 3.2. Элементы интерфейса

Пройдя процесс авторизации, пользователь попадает на главную страницу системы. На главной странице мы видим данные пользователя, под которым прошла авторизация, главную панель навигации (слева), и само рабочее окно. Рабочее окно выводит информацию согласно выбранного раздела из панели навигации.

- левая панель навигации по разделам;
- рабочая область текущего раздела;
- меню пользователя (аватар): профиль, роль, выход из системы;
- документация;
- техническая поддержка.

## 3.3. Добавление лицензий

Перед началом работы пользователю, необходимо убедится, что в личном кабинете присутствуют лицензии. Для этого в левом боковом меню перейдите в раздел Лицензии.

![3. Начало работы](/img/manual/image13.png)

Что отображется в разделе:

- сколько и каких лицензий у пользователя есть в наличии;
- сколько устройств уже привязано к лицензиям;
- когда истекают лицензии.

![3. Начало работы](/img/manual/image14.png)

Отгрузка лицензии для локальных серверов

Запрос лицензий

- В диалоговом окне указывается: количество лицензий, тип, тариф и дату начала работы
- Далее нажимается кнопка Сформировать – загрузится txt-файл запроса
- Сформированный файл отправляется менеджеру.

## 3.4. Установка дистрибутива

Для добавления устройства необходимо установить программное обеспечение SmartPlayer на требуемое устройство, запустить приложение и дождаться появления девятизначного цифрового кода на экране устройства.

## 3.5. Добавление устройства

После установки Дистрибутива, в меню навигации Личного кабинета, в пункте меню «Устройства» необходимо выбрать раздел «Добавить устройство».

![3. Начало работы](/img/manual/image18.png)

В появившемся окне необходимо ввести девятизначный код, полученный с устройства и нажать кнопку «Сохранить». Пример кода регистрации на устройстве представлен на изображении ниже: На открывшейся странице «Дополнительные параметры устройства» заполняется карточка устройства: название, адрес установки, часовой пояс, ориентация экрана, теги, текстовое описание и принадлежность той или иной группе устройств. Введённые данные сохраняются по нажатию кнопку «Сохранить».
