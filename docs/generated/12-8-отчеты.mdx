## 8.1. Типы отчетов

Поддерживаются отчеты:

- по устройствам;
- по трансляциям;
- по контенту.

## 8.2. Формирование и выгрузка

Общий порядок (пример сформированных отчетов на рис. 15):

1. Выберите тип отчета.
1. Укажите период (и при необходимости время).
1. Выберите устройства/группы.
1. Нажмите "Создать отчет".
1. Выгрузите готовый файл из списка сформированных отчетов.
