## 8.1. Типы отчетов

Поддерживаются отчеты:

по устройствам;

по трансляциям;

по контенту.

## 8.2. Формирование и выгрузка

Общий порядок (пример сформированных отчетов на рис. 15):

1. Выберите тип отчета.

2. Укажите период (и при необходимости время).

3. Выберите устройства/группы.

4. Нажмите "Создать отчет".

5. Выгрузите готовый файл из списка сформированных отчетов.
