## 2.1. Варианты предоставления решения

SmartPlayer поддерживает два базовых сценария:

- локальный сервер;
- облачный сервер.

## 2.2. Безопасность

В облачном сценарии обмен между клиентом и сервером выполняется по HTTPS. Возможна настройка двухфакторной авторизации. Для разграничения доступа применяются роли и права пользователей.

Система ведет журнал действий пользователей (раздел "История"), где фиксируются:

- тип события;
- описание события;
- дата и время;
- учетная запись.

## 2.3. Поддерживаемые платформы

Поддерживаемые клиентские платформы:

- Samsung (Tizen, Orsay);
- LG (WebOS, WebOS Pro: Centric);
- Android (включая профессиональные панели);
- Windows;
- Ubuntu;
- Raspberry Pi;
- BrightSign.

## 2.4. Поддерживаемые типы контента

- изображения: JPG, JPEG, PNG и GIF;
- видео: MP4;
- аудио: MP3;
- документы: PDF;
- веб-страницы: http и https;
- бегущая строка;
- потоковые источники: RTSP, RTP, UDP, HLS и RTMP (внедряется);
- виджеты: мини приложения.
